# Signal Generator App

`signals-generator-app` — настольное приложение на C# с графическим интерфейсом WPF для генерации, визуализации и обработки цифровых сигналов.

Приложение использует библиотеку `SignalProcessing.Core`, которая отвечает за основные алгоритмы генерации и обработки данных. Графический интерфейс позволяет выбирать тип сигнала, задавать параметры, отображать результаты и выполнять анализ.

## Основные возможности

- Генерация сигналов различных форм.
- Настройка параметров генерации через графический интерфейс.
- Отображение сигналов на графике.
- Добавление нескольких сигналов и управление ими.
- Фильтрация сигналов.
- Выполнение операций над сигналами.
- Чтение сигналов из файлов и сохранение результатов.
- Изменение частоты дискретизации.
- Анализ пересечений заданного порога.
- Отображение маркеров пересечения на графике.
- Подсчёт пересечений вверх и вниз.
- Определение минимального и максимального интервалов между пересечениями.

## Архитектура проекта

Приложение разделяет графический интерфейс и алгоритмы обработки сигналов.

Основные задачи распределены следующим образом:

- **signals-generator-app** — взаимодействие с пользователем, настройка параметров, отображение графиков и результатов анализа.
- **signals-core** — генерация сигналов, фильтрация, операции над сигналами, изменение частоты дискретизации и анализ пересечений порога.

Такое разделение позволяет использовать алгоритмы обработки независимо от графического интерфейса.

## Генерация сигналов

В приложении предусмотрен выбор типа генерируемого сигнала и настройка его параметров.

Поддерживаются следующие типы:

| Тип сигнала | Описание |
|---|---|
| Синусоидальный | Периодический сигнал синусоидальной формы |
| Линейный | Сигнал с линейным изменением значения |
| Шумовой | Сигнал со случайными значениями |
| Треугольный | Периодический сигнал треугольной формы |
| Пилообразный | Периодический сигнал пилообразной формы |
| Постоянный | Сигнал с неизменным значением |

Для генерации пользователь выбирает нужный тип сигнала, задаёт параметры и запускает создание сигнала.

Параметры передаются в библиотеку `SignalProcessing.Core`, где выполняется непосредственная генерация массива отсчётов.

## Визуализация сигналов

Для отображения данных используется библиотека ScottPlot.WPF.

Графическая область позволяет:

- отображать созданные и загруженные сигналы;
- добавлять несколько кривых;
- визуально сравнивать сигналы;
- обновлять график после обработки данных;
- отображать специальные маркеры результатов анализа.

Приложение также предоставляет элементы управления списком сигналов, позволяющие выбирать и удалять отдельные кривые.

## Обработка сигналов

Приложение использует алгоритмы библиотеки `SignalProcessing.Core` для выполнения операций над сигналами.

Доступны следующие возможности:

- применение фильтров;
- выполнение операций сложения и объединения;
- изменение частоты дискретизации;
- чтение данных из файлов;
- сохранение сигналов в файлы.

После выполнения обработки результат может быть отображён на графике.

## Анализ пересечений порога

В приложении реализован поиск моментов, когда сигнал пересекает заданный пользователем уровень.

Для выполнения анализа необходимо ввести значение порога и запустить поиск.

Определяются два направления пересечения:

- **Вверх (Up)** — сигнал пересекает порог снизу вверх.
- **Вниз (Down)** — сигнал пересекает порог сверху вниз.

Результаты анализа отображаются одновременно в графической области и в списке найденных пересечений.

Для каждого пересечения отображаются:

- время пересечения в секундах;
- значение сигнала;
- направление пересечения.

### Маркеры на графике

Найденные пересечения отмечаются специальными маркерами:

- зелёные маркеры — пересечения вверх;
- красные маркеры — пересечения вниз.

Маркеры позволяют визуально определить положение пересечений относительно исходной кривой.

### Дополнительная статистика

В приложении реализованы два дополнительных обработчика событий:

| Компонент | Назначение |
|---|---|
| `MarkerCounter` | Подсчитывает количество пересечений вверх и вниз |
| `MarkerIntervalAnalyzer` | Определяет минимальный и максимальный интервалы между соседними пересечениями |

Статистика обновляется во время анализа по мере обнаружения маркеров.

### Очистка результатов

Предусмотрена очистка результатов анализа. При её выполнении удаляются маркеры с графика, записи из списка и накопленная статистика.

При этом исходная кривая сигнала сохраняется.

При добавлении или удалении сигнала предыдущая разметка также очищается, чтобы результаты анализа не относились к уже изменённым данным.

Некорректное значение порога обрабатывается с выводом сообщения об ошибке, без аварийного завершения приложения.

## Запуск приложения

Для сборки и запуска требуется:

- Windows;
- Visual Studio с поддержкой C# и WPF;
- .NET Framework 4.8;
- необходимые пакеты NuGet, указанные в проекте.

Порядок запуска:

1. Откройте решение `SignalGenerator.sln` в Visual Studio.
2. Убедитесь, что проект `SignalProcessing.Core` доступен по указанному в решении пути.
3. Выполните восстановление NuGet-пакетов при необходимости.
4. Соберите решение через **Build → Build Solution**.
5. Запустите приложение через **Debug → Start Debugging** или клавишей F5.
