# signals-generator-app

Приложение WPF: генерация сигналов, фильтрация, графики. Содержит только код окна;
логика находится в библиотеке `signals-core`.

## Проекты
- `SignalGenerator.App` — приложение
- `SignalProcessing.Core` — библиотека из репозитория `signals-core` (подключена ссылкой)

Требуется .NET Framework 4.8 и пакет ScottPlot.WPF 4.1.x.

## Связанные репозитории
Библиотека находится в репозитории:
https://github.com/dinik1n/signals-core

Оба репозитория клонируются в одну папку, рядом друг с другом:

```
D:\<рабочий каталог>\
├── signals-core\
└── signals-generator-app\
```

`SignalGenerator.sln` ссылается на проект библиотеки по относительному пути
`..\signals-core\SignalProcessing.Core\`, поэтому имена и расположение папок менять нельзя.
Без `signals-core` решение не откроется.

## Запуск
1. Склонируйте оба репозитория в одну папку.
2. Откройте `SignalGenerator.sln`.
3. Соберите и запустите `SignalGenerator.App`.

## Возможности
- построение кривых, суммирование и склейка сигналов
- изменение частоты сигнала
- фильтры: скользящее среднее и медиана
- сохранение и загрузка сигнала из файла

Ошибки показываются в окне сообщения.
